# Factotum

Veille, agenda et journal des sorties culturelles de Léonard (théâtre, opéra, danse, concerts, expositions) : la saison notée et commentée, les soirs pris et l’archive de ce qui a été vu.

Site : https://factotumdellacitta.github.io/saison/

Factotum Expo (expositions, même code, accent vert Véronèse) : https://factotumdellacitta.github.io/saison/expo/

Données dans `data/` (zone privée chiffrée dans `prive.enc`), site dans `index.html`, `expo/` et `assets/`, outils dans `tools/`. Règles de maintenance, schémas et **charte graphique** : `CLAUDE.md` (section « Charte graphique ») et la page [`#charte`](https://factotumdellacitta.github.io/saison/#charte).
